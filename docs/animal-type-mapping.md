# 動物種コードマッピング

サトノメ標準フォーマット（RFC-001）で使用する動物種コードと、環境省鳥獣コードとの対応表。

## マッピングテーブル

| animal_code | 和名 | 環境省コード | 分類 | 被害件数（参考） |
|---|---|---|---|---|
| `DEER` | ニホンジカ | 0620 | 偶蹄目シカ科 | 最多 |
| `BOAR` | イノシシ | 0630 | 偶蹄目イノシシ科 | 多 |
| `MONK` | ニホンザル | 0410 | 霊長目オナガザル科 | 中 |
| `BRBR` | ツキノワグマ | 0510 | 食肉目クマ科 | 中（人身被害リスク高） |
| `BWBR` | ヒグマ | 0520 | 食肉目クマ科 | 北海道限定 |
| `RDOG` | タヌキ | 0310 | 食肉目イヌ科 | 中 |
| `CIVT` | ハクビシン | 0340 | 食肉目ジャコウネコ科 | 増加傾向（外来種） |
| `RACN` | アライグマ | 0350 | 食肉目アライグマ科 | 増加傾向（特定外来生物） |
| `NUTR` | ヌートリア | 0710 | 齧歯目ヌートリア科 | 西日本中心（特定外来生物） |
| `KYON` | キョン | 0640 | 偶蹄目シカ科 | 千葉・伊豆（特定外来生物） |
| `CROW` | カラス類 | 1010 | スズメ目カラス科 | 多（鳥類最多） |
| `SPAW` | スズメ | 1210 | スズメ目スズメ科 | 中 |
| `BBLB` | ヒヨドリ | 1110 | スズメ目ヒヨドリ科 | 果樹被害 |
| `DUCK` | カモ類 | 1310 | カモ目カモ科 | 水稲被害 |
| `PIGN` | ドバト | 1410 | ハト目ハト科 | 都市部 |
| `OTHR` | その他 | - | - | `description` に種名を記載 |

## コード設計原則

1. **4文字の英字大文字**（`[A-Z]{4}`）で統一
2. 種の英名または特徴的な部分から短縮
3. 環境省コードとの1対1マッピングを維持
4. `OTHR` は未定義種のフォールバック

## 環境省コード体系との関係

環境省の鳥獣コードは4桁の数値コード体系で、以下の構造を持つ：

- `0xxx`: 哺乳類
  - `03xx`: 食肉目
  - `04xx`: 霊長目
  - `05xx`: クマ科
  - `06xx`: 偶蹄目
  - `07xx`: 齧歯目
- `1xxx`: 鳥類
  - `10xx`: カラス科
  - `11xx`: ヒヨドリ科
  - `12xx`: スズメ科
  - `13xx`: カモ科
  - `14xx`: ハト科

サトノメの `animal_code` はこの数値コードの**人間可読なエイリアス**として機能し、APIやUIでの使用を容易にする。データ交換時は環境省コードへの変換が推奨される。

## 変換コード例

```typescript
const ANIMAL_CODE_TO_ENV: Record<string, string> = {
  DEER: '0620',
  BOAR: '0630',
  MONK: '0410',
  BRBR: '0510',
  BWBR: '0520',
  RDOG: '0310',
  CIVT: '0340',
  RACN: '0350',
  NUTR: '0710',
  KYON: '0640',
  CROW: '1010',
  SPAW: '1210',
  BBLB: '1110',
  DUCK: '1310',
  PIGN: '1410',
};

function toEnvCode(animalCode: string): string | undefined {
  return ANIMAL_CODE_TO_ENV[animalCode];
}
```
