## サトノメ標準フォーマットの優位性

1. **被害と捕獲の統合管理**: 被害報告・目撃報告・捕獲報告を1つのフォーマットで扱える
2. **GIS標準対応**: WGS84座標 + メッシュコードの両方をサポート
3. **API-First設計**: JSON Schema による機械可読なデータ定義
4. **省庁横断**: 農水省統計と環境省捕獲の両方への変換パスを持つ
5. **オープン仕様**: CC BY 4.0ライセンスで公開、誰でも実装可能
